# 모도 (Modo)

초기 카카오톡의 단순하고 빠른 메신저 경험을 오늘의 웹 기술로 다시 만드는 서비스입니다. 친구 목록과 프로필, 1:1·그룹 대화, 읽지 않은 메시지 표시처럼 메신저의 기본에 집중합니다.

## 제품 원칙

- 기능은 초기 메신저 시절의 범위로 제한합니다. 피드, 오픈채팅, 송금, 쇼핑, 게임, AI 기능은 제품 범위에 넣지 않습니다.
- 익숙한 채팅 경험은 살리되 카카오톡의 이름, 로고, 캐릭터, 화면을 복제하지 않습니다. 자체 브랜드와 시각 디자인을 사용합니다.
- Expo 기반 단일 앱 코드베이스로 웹과 iOS·Android를 지원합니다. 데스크톱 웹에서는 앱을 휴대폰 크기의 화면으로 보여주고, 모바일에서는 같은 화면이 전체 뷰포트를 채웁니다.
- 개인정보와 대화 접근은 기본 차단으로 시작합니다. 사용자 본인과 대화 참여자만 해당 데이터를 볼 수 있어야 합니다.

## 개발 시작

```sh
pnpm install
pnpm web
```

네이티브 개발은 `pnpm ios` 또는 `pnpm android`로 시작합니다. Expo SDK 버전은 `apps/app/package.json`에 고정되어 있습니다.

## Supabase 개발 연결

앱은 `apps/app`을 Expo 프로젝트 루트로 실행합니다. Modo 개발 Supabase 프로젝트의 URL과 publishable key는 `apps/app/.env`에 둡니다. 이 파일은 Git에서 제외됩니다. 실제 서비스 키는 앱에 넣지 않습니다. DB 구조는 `supabase/migrations/`에서 관리합니다. 초기 마이그레이션은 Modo 개발 프로젝트에 적용되어 있습니다.
